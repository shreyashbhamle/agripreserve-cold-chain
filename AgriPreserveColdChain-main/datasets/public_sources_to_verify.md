# Public dataset sourcing checklist

Before adding external data, record for each dataset:

- Exact dataset title and direct dataset page URL
- Author/provider and access date
- Licence and attribution requirements
- Fields, units, geography and date coverage
- Missing-data and quality limitations
- Whether it contains labelled spoilage/quality outcomes or only sensor measurements
- How it will be split into train/validation/test without leakage

Discovery portals: https://data.gov.in/ · https://zenodo.org/ · https://data.mendeley.com/ · https://www.kaggle.com/datasets

No external datasets are represented as downloaded in this project archive. The included CSVs are synthetic demo records.
