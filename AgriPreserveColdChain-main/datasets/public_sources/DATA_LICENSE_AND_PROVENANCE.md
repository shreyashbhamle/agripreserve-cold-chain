# License and provenance checklist

- Zenodo cold-storage experiment: review the record's license and citation before redistribution.
- Mendeley citrus dataset: source page specifies CC BY 4.0; retain attribution and citation.
- Kaggle fruit freshness images: source page lists CC0; still preserve the dataset source/author information.
- data.gov.in: platform states Government Open Data License - India for published datasets; verify the individual resource terms.
- Open-Meteo: read current API terms/attribution requirements before production use.
- OpenStreetMap: attribution is required; follow the tile usage policy and do not bulk-download tiles.

For every downloaded file, record: source URL, download timestamp, license, checksum, transformation steps, and whether it is live, historical, synthetic, or manually entered.
